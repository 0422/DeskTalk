## 🔴 高优先级

### 1. TTS 连接复用（部分实现）

**问题**：当前每轮对话重建 TTS WebSocket，约 0.6–0.8 秒建连开销。  
**目标**：常驻 TTS 连接，预期降低 ~0.7 秒/轮。  
**当前状态（V2）**：
- ✅ V2 已实现 V3 双向 Session + Session 级复用
- ⚠️ 但受限于 ESP32-S3 内部 RAM（单条 TLS 约 45 KB），常驻连接在 ASR 前被主动释放
- ✅ TTS 连接复用逻辑已实现，仅内存保护策略使其未真正启用

**剩余工作**：
- [ ] 评估 ESP-IDF mbedTLS 外部内存 + PSRAM 优化空间，验证双 TLS 共存可行性
- [ ] 或启用流式网关（仅 V1 工程有实现，V2 未移植），将 TLS 内存压力移至服务器
- [ ] 优先解决 V2 文档中的双 TLS 内存水位问题（`internal_min=71 B`）

**参考**：[V2代码说明.md 板载 TLS 内存限制](1-固件文档/V2代码说明.md#板载-tls-内存限制)

### 2. LLM HTTPS 长连接

**问题**：DeepSeek 每轮从零建连，含 DNS/TCP/TLS 握手约 0.3–1 秒。  
**目标**：复用 HTTP 连接，省去握手开销。  
**当前状态（V2）**：
- ❌ V2代码说明.md §HTTPS 长连接与双 TLS 危机：LLM 每轮从零建连，无连接复用
- 每轮 `chat()` 执行 `init → perform → cleanup`，无连接复用

**待实现**：
- [ ] 修改 `llm_client.cpp` 设置 `keep_alive_enable=true`
- [ ] handle 提升为成员变量跨轮复用，仅传输错误时重建
- [ ] 验证内部 RAM 水位：常驻 LLM + 常驻 TTS 双连接是否可行

**预期收益**：每轮节省 ~0.5 秒（握手开销）

### 3. VAD 句尾截断验证

**问题**：当前 VAD 静默阈值 500 ms，可能导致用户短暂停顿被误判为结束。  
**目标**：在短停顿场景（如"嗯……"、"就是"）验证识别完整性。  
**方案**：
- [ ] 20 轮短停顿 ASR 截断测试（与版本历史.md 的 20 轮延迟统计不是同一测试）
- [ ] 对比 ASR 最终文本与预期，统计截断率
- [ ] 若截断率 >5%，退回 650ms 或 900ms

## 🟡 中优先级

### 4. 摄像头人脸跟随（已处理，当前禁用）

**现状**：硬件已支持（GC2145 摄像头），V2 明确保持禁用，原因：
- 主 loop 同步推理会阻塞网络任务（500ms/帧）
- 当前固件已验证无需摄像头即可正常运行

**目标**：恢复人脸检测 + 头部跟随，并解决主循环阻塞问题。  
**重新激活前提**：
- [ ] 将 `handle_face_tracking()` 改为独立 FreeRTOS 任务或降低推理频率
- [ ] 验证并发写 GPIO12/13 的舵机抖动问题
- [ ] 验证无人脸时 `random_act()` 能否正常触发（V1 审查"空闲头部僵住"问题）

### 5. 手势传感器（已处理，当前禁用）

**现状**：PAJ7620U2 硬件已列入物料清单，V2 明确保持禁用。代码中有开关但未验证，原因：
- I2C 引脚占用（GPIO1/2）需确认是否与现有外设冲突
- Arduino 库 `RevEng PAJ7620` 在 ESP-IDF 下的兼容性未验证

**目标**：支持 9 种手势识别触发动作。  
**待验证**（重新激活前）：
- [ ] I2C 引脚占用（GPIO1/2）是否与现有外设冲突
- [ ] 在 ESP-IDF 下验证 `RevEng PAJ7620` 库兼容性

### 6. 双麦拾音优化

**现状**：仅使用 INMP441 左声道，右声道并联但未使用。  
**目标**：实现立体声采集 + 软件下混，改善拾音距离和信噪比。  
**方案**：
- [ ] 改为 I2S 立体声模式（`I2S_CHANNEL_FMT_RIGHT_LEFT`）
- [ ] 32-bit 原始数据右移 16 位转 16-bit PCM
- [ ] (L + R) / 2 下混或选择信噪比更优的单声道
- [ ] 实测校准左右声道增益

## 🟢 低优先级 / 未来探索

### 7. 配置类功能（多 LLM / 多唤醒词 / 情感驱动动作）

**目标**：支持切换 LLM 供应商、动态增删唤醒词、按情感自动匹配表情动作。  
**状态**：方案细节与代码位置见 [1-固件文档/V2代码说明.md §待实现功能](1-固件文档/V2代码说明.md#待实现功能)，此处不再重复。

### 8. 本地离线 TTS

**目标**：断网时仍能回复，降低云端依赖。  
**方案**：
- [ ] 集成 sanoTTS（int8 模型 337 KB，RTF 0.38）
- [ ] 预录音色包（高频应答短语）
- [ ] 网络检测 + 自动降级路由

**现状**：WS2812 固定亮度，暗室刺眼。  
**目标**：根据环境光（光敏电阻）或时间自动调节亮度。
