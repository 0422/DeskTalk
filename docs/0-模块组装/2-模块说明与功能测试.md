

# 舵机
舵机上自带的橙/红/棕 3 芯线是母头 3 P 插座，橙=信号，红=VCC，棕=GND，这是舵机的通用配色，两个 MG 90 S 云台（X/Y）用于信号+供电。

归中：先不装支架，舵机单独用杜邦线接到 ESP32 上，烧录归中程序。
或在桌面端上位机中，一键归中。

> 见测试目录

本项目使用**ESP32-S3 + 两个 PWM 舵机** 做 2 自由度云台。

它的舵机控制非常典型：X 轴接 GPIO 12，Y 轴接 GPIO 13，用标准的 50Hz PWM 脉冲来控制头部左右转动和上下点头。

这意味着你在做它的过程中，已实际接触了 PWM 舵机的核心控制逻辑——包括角度范围限制、中心位校准、步进增量移动这些基础操作。这套代码结构可以直接迁移到任何 PWM 舵机项目上。

# OLED
OLED 屏，板子上丝印了 GND/VCC/SCL/SDA 字样，必须严格按字样连接。

有 GND/VCC/SCL/SDA 丝印标注的是 $I^2C$ 屏幕，
买的这个是SSD1306 芯片，不是通电就亮，需要主控芯片发一串初始化指令（通过 I2C，也就是 SDA/SCL 那两根线）它才会点亮显示内容。

通过 ESP32 I2C scanner 程序（编译传输后，Ctrl + Shift + M 打开串口监视器，右侧下拉选择 115200 baud）查看输出显示OLED 的 I²C 地址确认是 0x3C。

# ESP32-S3
ESP 32 板上的丝印：
上排：VIN GND D13 D12 D14 D27 D26 D25 D33 D32 D35 D34 VN VP EN
下排：BOOT 3V3 GND D15 D2 D4 Rx2 Tx2 D5 D18 D19 D21 RX0 TX0 D22 D23

ESP32-S3 GPIO Extension Board将**ESP32-S3-N16R8**核心板的所有GPIO引出并标准化，同时提供了电源、串口和复位等基础电路。ESP32-S3 GPIO Extension Board 的主控芯片是 **CP2102**（USB转串口芯片）：
- 将核心板的3.3V GPIO全部以2.54mm排针引出
- 提供稳定的5V和3.3V电源输出
- 集成USB转串口（用于烧录和日志）
- 提供复位和BOOT按键（方便下载）




# 手势传感器
PAJ7620U2，提供 VCC/GND/SDA/SCL 引脚，使用 I2C 通信。
支持 3.3V 逻辑电平，支持 9 种手势识别。
尽量选择明确标注兼容 Arduino/ESP32 的模块。


INT 是 PAJ7620U2 的中断输出引脚。
检测到手势时，它可通知 ESP32 读取结果，通常为低电平有效。
INT 不要接 GND、3.3V，也不要并到 SDA/SCL。
将该引脚绝缘避免意外短路即可。
以后若改成中断触发，可以把它接到一个空闲的输入 GPIO，并同步修改程序；目前没有必要。

喇叭红线为正极 (+)，黑线为负极 (-)。
如果喇叭线头带有白色的塑料插头或金属端子，**必须剪掉**。
剥开红黑线头约 **5mm** 的绝缘皮，铜丝并稍微拧紧（避免有散落的毛刺）。
拧松B 处的螺丝，然后铜丝塞入 A 处的孔，拧紧螺丝。
