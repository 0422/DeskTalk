# 汇总说明

当前程序只会采集 L/R=GND 的左麦，右麦不会参与语音识别，可以只插一个麦克风，或修改程序使支持双麦。双麦共用 SD、WS、SCK 的接法本身正确，但并联不会自动获得降噪效果。
> 如果只是给 ASR 录音，建议暂时保留 ONLY_LEFT，使用一个声道最稳妥。
> 如果确实需要两个麦克风同时工作，则还要把输入改为立体声采集、按 INMP441 的 32 位槽读取，再将左右声道混合成 16 位单声道；ASR 当前声明的是单声道，不能只把 ONLY_LEFT 改成 RIGHT_LEFT 就结束。

## ESP32-S3 直连方案
（单麦、无手势追踪），需要从 ESP32-S3 底板上引出的电源数量如下：

| 设备          | 数量      |
|-------------|---------|
| OLED VCC    | 1       |
| INMP441 VDD | 1       |
| 合计          | 2 个 3V3 |
两个都是低功耗，ESP32-S3 底板通常只有 **1 个 3V3 排针**，所以你需要**一拖二**，从 3V3 分给 OLED 和单麦。

| 设备           | 数量     | 是否建议走底板 5V |
|--------------|--------|------------|
| MAX98357 VIN | 1      | 可以，功放电流中等  |
| X 轴舵机        | 1      | 不建议        |
| Y 轴舵机        | 1      | 不建议        |
| 合计           | 3 个 5V |
底板通常也只有 **1 个 5V 排针**。如果三个都从底板 5V 一拖三：
- MAX98357 功放：中等电流，问题不大
- 两个 MG90 舵机：同时动可能 1A+，**底板 5V 和 USB 供电扛不住**，容易复位

```file:推荐接法
底板 3V3 → 一拖二 → OLED VCC
                  → INMP441 VDD
                  
                  
底板 5V → MAX98357 VIN（功放单独走底板）
独立 5V 电源 → 一拖二 → X 轴舵机红线
                     → Y 轴舵机红线
              └→ GND 与 ESP32 共地
```



| 线           | 用途              | 数量        |
|-------------|-----------------|-----------|
| 一拖二杜邦线（母对母） | 3V3 分给 OLED + 麦 | 1 根       |
| 一拖二杜邦线（母对母） | 独立 5V 分给两个舵机    | 1 根       |
| 普通杜邦线       | 5V 给功放          | 1 根       |
| GND 一拖多     | 所有设备共地          | 建议用面包板电源轨 |
