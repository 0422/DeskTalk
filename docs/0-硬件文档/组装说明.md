# 组装说明

本文档描述 Desk-talk 机器人的组装步骤和注意事项。

## 组装前准备

1. **阅读 [材料清单.md](材料清单.md)**：确认所有物料齐全
2. **阅读 [接线说明.md](接线说明.md)**：了解 GPIO 引脚映射和接线规则
3. **阅读 [模块说明.md](模块说明.md)**：了解各模块功能测试方法

## 组装步骤

### 1. 云台组装

- 参考 [attachments/0-金属二自由度云台安装教程.pdf](attachments/0-金属二自由度云台安装教程.pdf)
- 舵机先不装支架，单独用杜邦线接到 ESP32 上
- 烧录归中程序，或在桌面端上位机中一键归中

### 2. 底板接线

按照 [接线说明.md](接线说明.md) 完成杜邦线连接，特别注意：

- **共地**：所有设备 GND 必须共地
- **电源**：
  - ESP32 3V3 → 一拖二 → OLED VCC + INMP441 VDD
  - ESP32 5V → MAX98357 VIN（功放单独走底板）
  - 独立 5V 电源 → 一拖二 → X/Y 轴舵机红线 + GND 共地
- **I2C 地址**：OLED 确认地址为 `0x3C`

### 3. 喇叭接线

- 红线为正极 (+)，黑线为负极 (-)
- 剪掉线头的白色塑料插头或金属端子
- 剥开绝缘皮约 5mm，拧紧铜丝
- 塞入功放正/负极孔，拧紧螺丝
- **注意**：喇叭负极不得接 GND

### 4. 电源验证

- 先断开舵机，仅保留 OLED
- 用"眨眼"测试验证串口通信正常
- 确认无供电问题后再连接舵机

## 常见问题

### 舵机供电不足

- 症状：串口写入失败，舵机抖动或不动作
- 解决：舵机使用稳定的 5V 电源（建议 5V 2A），GND 与 ESP32 共地

### OLED 不亮

- 确认 I2C 地址为 `0x3C`
- 检查 SDA/SCL 是否接反
- 确认 3V3 供电正常

### 串口通信失败

- 关闭 Arduino IDE 串口监视器
- 检查 COM 口是否变化
- 重新插拔 USB，刷新端口
