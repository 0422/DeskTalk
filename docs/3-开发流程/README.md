## 🔧 开发环境

### Arduino IDE（V1 版本）

- **框架**：Arduino ESP32 3.0.0，开发板 ESP32S3 Dev Module
- 完整配置选项与依赖库版本见 [烧录说明](烧录说明.md)。

### ESP-IDF（V2/V3 版本）

- **框架**：ESP-IDF v5.3.x（推荐 v5.3.5）
- **构建**：`idf.py build`
- **烧录监视**：`idf.py -p COM4 app-flash monitor`

详见 [烧录说明](烧录说明.md)。
