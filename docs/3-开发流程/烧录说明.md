# 烧录流程

> **V1 版本**：使用 Arduino 框架，工程目录 `V1/Arduino_esp32s3_v0.0.1/Arduino_esp32s3_v0.0.1/`
>
> **V2/V3 版本**：使用 ESP-IDF v5.3.x，详见下方说明

## Arduino IDE 配置（V1）

1. 编译前修改工具栏设置：

| Arduino IDE 选项 | 设置 |
|----------------|------|
| 开发板 | ESP32S3 Dev Module |
| CPU Frequency | 240MHz (WiFi) |
| Flash Mode | QIO 80MHz |
| Flash Size | 16MB (128Mb) |
| Partition Scheme | Desk-talk 16M (6MB APP/ESP-SR MODEL) |
| PSRAM | OPI PSRAM |
| Upload Speed | 921600（不稳定时改 115200） |

2. **首次烧录**：
   - 将 `Erase All Flash Before Sketch Upload` 设置为 **Enabled**
   - 重新上传固件
   - 上传完成后改回 **Disabled**
   - 打开串口监视器（115200 baud），按复位键

⚠️ 完整擦除会清除 Wi-Fi 配置、聊天记录、舵机校准等 Flash 数据，需要重新配网。

3. **依赖库安装**：

| 库名 | 作者 | 版本 |
|------|------|------|
| Adafruit BusIO | Adafruit | 1.17.4 |
| Adafruit GFX Library | Adafruit | 1.12.6 |
| Adafruit NeoPixel | Adafruit | 1.15.5 |
| Adafruit SSD1306 | Adafruit | 2.5.17 |
| ArduinoJson | Benoit Blanchon | 7.4.3 |
| ESP32Servo | Kevin Harrington, John K. Bennett | 3.0.0 |
| RevEng PAJ7620 | Aaron S. Crandall | 1.5.0 |

## ESP-IDF 配置（V2/V3）

### 环境要求

- ESP-IDF v5.3.x（推荐 v5.3.5）
- Python 3.9–3.11
- 串口工具：`idf.py -p COM4 monitor`

### 编译与烧录

```bash
# 构建
idf.py build

# 烧录 + 监视器
idf.py -p COM4 app-flash monitor
```

监视器快捷键：
- `Ctrl+]`：退出监视器
- `Ctrl+T`、`Ctrl+L`：开启/停止日志保存

### 密钥配置

复制并编辑密钥配置文件：

```bash
cp main/secrets.example.h main/secrets.h
# 编辑 main/secrets.h，填入火山引擎和 DeepSeek 凭据
```

> ⚠️ `secrets.h` 已加入 `.gitignore`，不会被提交到版本库。

### 火山引擎（ASR + TTS）

- 申请试用**豆包流式语音识别模型 2.0** 和 **豆包音频生成模型 2.0**

### DeepSeek LLM

- 使用官方 API：`https://api.deepseek.com/chat/completions`
- 模型：`deepseek-flash`
- 密钥配置在 `secrets.h`

## 上位机测试（V1 专用）

### 环境准备

```bash
conda create -n desk-talk python=3.11 -y
conda activate desk-talk
# 在仓库根目录下进入上位机工程（V1 专用）
cd V1\pc_client_gemini_v3.1
python -m pip install -r requirements.txt
```

启动前注意：
- 关闭 Arduino IDE 串口监视器（避免占用 COM 口）
- 命令行窗口不要关闭（关闭后客户端退出）

### 常见问题

**串口写入失败**：
- 关闭客户端，拔掉 USB
- 暂时断开舵机，只保留 OLED
- 重新插 USB，启动客户端，刷新端口
- 先点击”眨眼”测试：成功说明串口正常，失败检查供电

**舵机供电不足**：
- 使用稳定 5V 电源（建议 5V 2A）
- 舵机红线接 5V，棕/黑线接 GND
- 外部电源 GND 必须与 ESP32 GND 共地
- 不要从 ESP32 的 3.3V 给舵机供电

**客户端断线残留状态**：
- 写入失败后内部仍保留”已连接”状态
- 需关闭客户端，重新插拔 ESP32，再启动连接

**表情控制延迟大**（约 1 秒）：
- 成因：客户端发送 JSON 时未追加换行符，ESP32 等串口超时
- 修复：客户端发送时追加 `\n`，即 `(msg + “\n”).encode(“utf-8”)`

## 交互链路

```
INMP441 麦克风
    ↓ I2S 数字音频
ESP32-S3 采集 16kHz 单声道录音
    ↓ WebSocket
火山引擎 ASR：语音转文字
    ↓ 文本
LLM：生成回答文本和表情/动作指令
    ↓ 回答文本
火山引擎 TTS：文字转 16kHz PCM 音频
    ↓ I2S 数字音频
MAX98357 功放
    ↓
喇叭播放
```
