# 外壳设计

本文档记录 Desk-talk 机器人的外壳结构设计、开孔位置和装配说明。

## 设计背景

在 V1 基础上继续设计与调整机器人外壳结构，以适配屏幕、摄像头、舵机、麦克风和扬声器等硬件布局。

## 结构说明

### 底板与顶板

- **底板 / 顶板**：均为矩形
- **四个角开孔**：孔心间距 76.08 mm，孔半径 1.5 mm

### 顶板居中新孔

1. **云台底座开孔**：长边孔心间距 43.74 mm，短边孔心间距 23.28 mm，孔半径 1.5 mm
2. **麦克风窗口**：10.20 × 10.20 mm
3. **功放露出窗口**：7.70 mm × 7.46 mm
4. **喇叭开孔**：开孔间距 45.5 mm，孔心 3.5 mm（⚠️ 开孔错误待修正）
